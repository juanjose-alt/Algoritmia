# Café Origen - Motor de Analítica v0.1 

Motor de procesamiento de datos de ventas desarrollado para el análisis comercial de "Café Origen".

¿Qué es? 
Es una herramienta en Node.js que procesa un set de datos de ventas para calcular indicadores clave (totales, unidades, ticket promedio, etc), agrupar ventas por ciudad y producto, generar rankings de los productos más rentables y analizar transacciones por fecha sin mutar los datos originales.

¿Cómo ejecuitarlo? 
Asegúrate de tener Node.js instalado y ejecuta. 

Preguntas que responde: 
¿Cuánto es el total vendido y las unidades totales?

¿Cuál es el ticket promedio por transacción?

¿Cuánto se vende por cada ciudad (sin duplicados)?

¿Cuáles son los productos más vendidos y el top 3 de mayor valor?

¿Cómo se comportan las ventas en un día específico con o sin transacciones?
